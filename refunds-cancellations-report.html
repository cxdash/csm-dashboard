⚠ Data Quality — Flagged Refund Amounts

Annual Sub Refund entries whose USD-equivalent exceeds $3,000. Amounts are entered in local currency (GBP, EUR, PHP, ARS, etc.) and converted using approximate FX rates — a high raw number may not be a data error once converted. Some entries contain multiple amounts (e.g. "$718, $132, $102") which are summed automatically. All flagged entries should be verified against Recurly/Finance before actioning.
